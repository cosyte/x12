`serializeX12` takes a new opt-in option, `byteExact`: `serializeX12(ix, { byteExact: true })` returns the text `parseX12` read, byte for byte, for an interchange you did not edit, so line breaks between segments, a doubled terminator, a missing final terminator, the bytes after the IEA and a TA1's position all come back as they arrived. An interchange that was edited, copied or built emits from the model exactly as without the option, and so does every call that leaves the option off, so nothing a caller does today changes. A `Buffer` input comes back one character per octet: write it with `Buffer.from(out, "latin1")`. The first byte-exact emit of an interchange parses its source once more to compare against and keeps that emit, a second copy of the input of about its size, for as long as the interchange is reachable; later ones reuse it. An edit that changes nothing the emit writes (a typed `segments` array, the `warnings`) is not seen, as it is not seen without the option. To make this possible, `parseX12` keeps a reference to the text it read, beside the interchange rather than on it, for as long as the interchange is reachable; the interchange's shape is unchanged.
